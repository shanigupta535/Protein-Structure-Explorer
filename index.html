What you can do

Everything runs in your browser — no install, no account, no server of your own.

🔎

Search

Look up any of the 200,000+ experimental structures by PDB ID or full-text protein name.

🧬

3D Visualization

Rotate, zoom and inspect structures with the Mol* molecular viewer used by RCSB PDB itself.

📊

Analysis

Chains, sequences, ligands, resolution, atom counts and composition — all from live data.

⬇️

Download

Export coordinates in PDB / mmCIF format and sequences in FASTA format.

How to use

Four steps. Works the same on a phone and on a laptop.

1

Enter an ID

Type a 4-character PDB ID like 1TUP, or any protein name such as hemoglobin.

2

Open the explorer

The dashboard loads the 3D model on the left (top on mobile) and live metadata on the right.

3

Switch tabs

Use Overview, Sequence, Chains and Ligands to dig into the structure. Tap a chain to isolate it.

4

Download

Use the Download button in the top bar to save the structure file or the sequence.

About this platform

Protein Structure Explorer is an open, browser-based bioinformatics interface built on top of the RCSB Protein Data Bank public REST API and the Mol* molecular visualization engine. It does not store or redistribute structural data — every query is answered live by RCSB PDB servers. All scientific content remains the property of the original depositors. This is an independent educational project and is not affiliated with or endorsed by RCSB PDB or any government agency.
